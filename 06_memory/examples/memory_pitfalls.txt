=== 陷阱 1: 可变默认参数 ===
bad: r1=[1, 2, 3], r2=[1, 2, 3], r3=[1, 2, 3]
good: r1=[1], r2=[2]

=== 陷阱 2: 列表乘法创建引用 ===
bad matrix:  [[1, 0, 0], [1, 0, 0], [1, 0, 0]]
good matrix: [[1, 0, 0], [0, 0, 0], [0, 0, 0]]

=== 陷阱 3: += 对可变和不可变对象的行为不同 ===
int: a=11, b=10 (b 不变)
list +=: a=[1, 2, 3], b=[1, 2, 3] (b 也变了！)
list + : a=[1, 2, 3], b=[1, 2] (b 不变)

=== 陷阱 4: tuple 中的可变元素 ===
tuple with mutable: ([1, 2, 3], [3, 4])
t[0] += [3,4]: TypeError 但 t = ([1, 2, 3, 4],)

=== 陷阱 5: 大对象的内存 ===

字符串拼接 (50000 次):
  += 方式: 0.0061s
  join:    0.0082s
  加速比:  0.7x

=== 内存优化技巧 ===
普通类实例: 48 + 296 bytes
__slots__: 48 bytes

1000 个 int:
  list:  8,056 bytes
  array: 4,200 bytes
