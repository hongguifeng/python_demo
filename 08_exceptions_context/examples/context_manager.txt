=== 上下文管理器 vs RAII ===
相同点:
  - 都保证资源清理
  - 都能处理异常

不同点:
  - RAII 是隐式的（作用域结束自动调用）
  - with 是显式的（必须在 with 块中）
  - RAII 绑定到对象生命周期
  - with 绑定到代码块

  C++:
    {
        std::lock_guard<std::mutex> lock(mtx);
        // 自动释放
    }

  Python:
    with lock:
        # 自动释放
        pass

  Python 没有隐式 RAII，因为 __del__ 调用时机不确定。
  所以需要 with 来保证确定性清理。
