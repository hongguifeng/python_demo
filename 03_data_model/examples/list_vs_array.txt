=== 创建 list ===
nums = [1, 2, 3, 4, 5]
mixed = [1, 'hello', 3.14, [1, 2]]

=== 基本操作（对比 std::vector）===
append(4): [1, 2, 3, 4]
insert(0,0): [0, 1, 2, 3, 4]
pop(): got 4, list = [0, 1, 2, 3]
pop(1): got 1, list = [0, 2, 3]
remove(5): [0, 2, 3, 6, 7]
clear(): []

=== 内存模型（C 开发者关注）===
list 内存: 136 bytes (10 个元素)
  对比: C 的 int[10] = 40 bytes
  开销来源: PyObject* 指针 + 对象头 + 预分配空间
  len= 1, size=  88 bytes (增长!)
  len= 5, size= 120 bytes (增长!)
  len= 9, size= 184 bytes (增长!)
  len=17, size= 248 bytes (增长!)

=== 排序（对比 qsort/std::sort）===
sort(): [1, 1, 2, 3, 4, 5, 6, 9]
sort(key=len): ['date', 'apple', 'banana', 'cherry']
sorted(reverse=True): [5, 4, 3, 1, 1]
original unchanged: [3, 1, 4, 1, 5]

=== list 作为栈和队列 ===
栈: push 1,2,3 then pop → 3, stack = [1, 2]
队列: enqueue 1,2,3 then dequeue → 1, queue = [2, 3]

=== list 判等与比较 ===
a == b: True
a is b: False
[1,2] < [1,3]: True
[1,2] < [2,0]: True
