=== 不可变对象（int）的绑定 ===
x = 42, y = 42
id(x) = 0xb365c8, id(y) = 0xb365c8  (指向同一对象)
x is y: True

修改 x = 100 后:
x = 100, y = 42
id(x) = 0xb36d08, id(y) = 0xb365c8  (现在指向不同对象)

=== 可变对象（list）的绑定 ===
a = [1, 2, 3]
b = [1, 2, 3]
a is b: True

a.append(4) 后:
a = [1, 2, 3, 4]
b = [1, 2, 3, 4]   ← b 也变了！因为 a 和 b 是同一个对象

=== 正确的复制方式 ===
a = [1, 2, 3, 4]
b = [1, 2, 3]   ← 不受影响
c = [1, 2, 3]   ← 不受影响
d = [1, 2, 3]   ← 不受影响

=== 深拷贝 vs 浅拷贝 ===
original: [[1, 2, 99], [3, 4]]
shallow:  [[1, 2, 99], [3, 4]]  ← 内层对象被影响了！
deep:     [[1, 2], [3, 4]]     ← 完全独立
