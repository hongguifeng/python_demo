=== 基本 dataclass ===
p1 = Point(x=3.0, y=4.0)
p1 == p2: True

=== 默认值和工厂 ===
默认: Config(host='localhost', port=8080, tags=[])
自定义: Config(host='example.com', port=443, tags=['prod', 'api'])

=== 不可变 dataclass (frozen) ===
red = Color(r=255, g=0, b=0), hex = #ff0000
颜色字典: {Color(r=255, g=0, b=0): 'red', Color(r=0, g=255, b=0): 'green'}

=== 排序支持 ===
排序: ['v1.9.1', 'v1.10.0', 'v2.0.0']

=== 继承 ===
circle = Circle(color='red', radius=5.0), area = 78.54

=== __post_init__ — 初始化后处理 ===
employee = Employee(first_name='Alice', last_name='Smith', salary=50000, full_name='Alice Smith')

=== 转换工具 ===
asdict:  {'x': 3.0, 'y': 4.0}
astuple: (3.0, 4.0)

=== 对比传统写法 ===
传统类需要手写:
  class Point:
      def __init__(self, x, y):
          self.x = x
          self.y = y
      def __repr__(self):
          return f"Point({self.x}, {self.y})"
      def __eq__(self, other):
          return self.x == other.x and self.y == other.y
      def __hash__(self):
          return hash((self.x, self.y))

dataclass 一行搞定:
  @dataclass(frozen=True)
  class Point:
      x: float
      y: float
